# Railway-Delay-Prediction
Indian Railway Delay Prediction is a Machine Learning project developed to analyze historical railway journey data and predict train delays. The project focuses on two main tasks: Regression, which predicts the expected delay duration in minutes, and Classification, which predicts whether a train journey is likely to be delayed or not.

The project follows a complete Machine Learning workflow, including data analysis, data cleaning, preprocessing, feature engineering, model training, hyperparameter tuning, model comparison, and performance evaluation. Multiple regression and classification algorithms are implemented and compared using appropriate evaluation metrics such as R², RMSE, MAE, Accuracy, Precision, Recall, and F1-Score.

The best-performing models are selected and used to generate predictions for unseen railway data. The project aims to identify patterns related to train delays and demonstrate how Machine Learning can support better analysis and prediction of railway operations.
